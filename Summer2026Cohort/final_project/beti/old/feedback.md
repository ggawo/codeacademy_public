## Menu

Make the menu fixed. use style `position: sticky;`

## Header

Add Header below the menu

#### in the html:

```
<header>
        <div class="header-content">
            <h1>Big Header goes here</h1>
            <h3> Sub header , some message etc</h3>
        </div>

    </header>
```

#### in the css

The Header will have the following style:

```
.header-content {
    display: flex;
    flex-direction: column;
    align-items: center;
    justify-content: center;
    text-align: center;
    padding: 2rem 1rem;
    background-color: #e6ab23;
    color: rgb(6, 32, 204);
    background-image: url('any_image_you_want_to_add_as_background.jpg');
    background-size: cover;
    background-position: center;
    background-repeat: no-repeat;
}
```

## Footer

You can use the header styles as footer.
